# Amigos Superadmin ? Source Export

This ZIP contains the integrated Next.js restaurant site and its superadmin portal, including the admin routes, shared components, styles and static assets. The original files are from GitHub commit 1034ee7.

To run locally:

1. Extract this ZIP, open the `amigos` folder in VS Code.
2. Install Node.js and run `npm ci`.
3. Run `npm run dev`.
4. Visit `http://localhost:3000/admin`.

Notes: The admin is a demo frontend with browser/local mock state, not a production-secured backend or live database. Do not treat browser-only access as authentication. No node_modules, Git metadata or `.env` files are included.
